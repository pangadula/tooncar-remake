# ToonCar Remake

Strona fanowskiego remake'u gry ToonCar: <https://pangadula.github.io/tooncar-remake/>

Pliki do pobrania (Windows, Linux, Android, tekstury 4×) są w zakładce
[Releases](https://github.com/pangadula/tooncar-remake/releases/latest).
Do gry potrzebna jest własna instalacja ToonCara PL z 2001 r.

To repozytorium zawiera tylko stronę. ToonCar i oryginalne materiały należą do ich właścicieli.
